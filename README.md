### 🎮 Kitsos Island

My CV, except you walk around it. A frontend-only 3D island where townspeople tell you
about my career, seven buildings open up and let you walk **inside**, and five hidden keys
unlock the Old Lighthouse. No backend, no API keys, no fetches — the terrain, the
characters and even the soundtrack are generated in code.

Built with **React 19 · three.js · @react-three/fiber · TypeScript · Vite · Zustand**.
